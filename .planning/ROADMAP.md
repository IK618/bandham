# Roadmap: Bandhan Matrimonial

## Overview

Bandhan Matrimonial evolves from a robust trust-first foundation into an intelligent matrimonial ecosystem powered by explainable compatibility reasoning, automated profile polishers, biometric verification, and real-time conversational guardrails.

## Phases

- [x] **Phase 1: Foundation & Identity Core** - Complete identity onboarding, RBAC, and admin approval gates.
- [x] **Phase 2: 4-Pillar Trust Shield & Photo Studio** - Govt ID, Selfie liveness, and dynamic watermarks.
- [x] **Phase 3: Matchmaking, Contacts & Real-time Chat** - Compatibility engine, 1-credit reveal, and chat threads.
- [x] **Phase 4: Admin Governance & Performance Auditing** - Census metrics, N+1 query elimination, and web guidelines.
- [ ] **Phase 5: AI Matchmaking & Trust Biometrics** - AI matchmaker, biodata narrative generator, face-liveness biometrics, and automated content moderation.
